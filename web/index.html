3D Semantic Vector Space Explorer

Each sphere is one document from the 20 Newsgroups corpus, placed by its meaning: 384-dimensional sentence embeddings projected to 3D. Documents that are close together are semantically similar.

What you see

  • Color = topic cluster (K-Means on the embeddings). The legend shows each cluster's top keywords.
  • Size = document length in words, not importance.
  • Blue lines = semantic similarity (cosine). Brighter and thicker means more similar.
  • Gray lines = same source category.

Try it: simulate a RAG query

Click any sphere. It becomes the query, and the 8 most similar documents are retrieved ( gold lines). This is exactly the context a RAG system would hand to the language model. Click an entry in the side list to jump to that document.
